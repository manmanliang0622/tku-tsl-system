# 文字 → 手語輸出:設計與路線圖

`web/viewer.html` 的「手語合成」面板是 v1 實作。本文件記錄設計決策、
目前限制與後續路線。

## 目標

輸入中文文字,虛擬人輸出對應的手語動作。終極目標是自然台灣手語(TSL),
但這需要真正的翻譯層;v1 從「詞彙拼接」開始,把管線先打通。

## v1 架構(已實作)

```text
標註工具 ──▶ lexicon.json ──▶ 斷詞 ──▶ 切段 ──▶ 縫合 ──▶ 播放
(viewer)    (詞彙 → 錄製片段)  (貪婪最長匹配)        (交叉過渡)   (2D/3D 共用)
```

1. **詞彙庫** `recordings/lexicon.json`:
   `{ "詞彙": { "recording": "檔名.json", "start": 秒, "end": 秒 } }`
   每個詞條指向某段 recording 的時間區間。由 viewer 的標註工具維護
   (播放中設起點/終點 → 命名 → POST `/lexicon`)。
2. **斷詞**:貪婪最長匹配(先比對最長的詞條),空白與標點也切分。
   詞彙庫外的字元回報「略過」,不猜。
3. **合成**:各片段照 recording 時間軸切出 → 重新編時間 → 相鄰片段之間
   產生 0.28 秒的內插幀(landmark 空間線性插值:雙手、pose、blendshapes
   全部過渡)→ 組成一個合成 recording 物件 → 走既有的 `loadRecording()`,
   2D 骨架、3D 虛擬人、時間軸全部直接可用。

### v1 的誠實限制

- **逐詞對應 ≠ 自然手語**。中文語序直接拼接是「文字手語」;自然 TSL 的
  語序(主題—述語)、時間詞前置、否定後置、分類詞述語等都需要語法轉換層。
- 詞條目前是**句子級**(從財神到 MV 依字幕切的),真正可組合的詞彙庫
  需要**單一手語詞**級別的切分(建議錄製或找單詞素材重建)。
- 過渡是純線性插值,沒有考慮手的移動距離(遠距離換位會顯得快)。
- 非手部訊號(表情文法)只是跟著片段走,沒有依句型生成
  (疑問句挑眉、否定搖頭等)。

## 路線圖

| 階段 | 內容 |
|---|---|
| v1 ✅ | 句段詞庫 + 拼接 + 交叉過渡 |
| v1.5 ✅ | 詞級詞庫:`signavatar corpus ingest` 從文化部臺灣手語語料庫依逐詞毫秒時間戳自動建詞條(`src/signavatar/corpus.py`、`lexicon.py`) |
| v2 ✅ | 過渡改進:依手腕距離調整過渡時長(0.12–0.55s);首尾中立位修剪(手腕速度門檻,單側上限 25%/0.8s,`composer.js trimNeutral`) |
| v2.5 ✅ | 中文→TSL 翻譯層(`translate.py` + `POST /translate`):LLM(本機 claude CLI,受限詞彙輸出)+ 規則式 fallback(時間詞前置、否定後置、丟虛詞);**規則仍需聾人顧問驗證** |
| v3 ✅(v1 版) | 非手部訊號:是非問句挑眉、wh 問句皺眉(最後一個手語詞)、否定 ~3Hz 搖頭(`applyNMM`) |
| v3+ | 首尾中立位修剪、mouthing、空間文法(呼應動詞 loci)、聾人審核迴圈、資料集擴充、學習式翻譯 |

完整設計與研究依據:`docs/superpowers/specs/2026-07-05-tsl-generation-design.md`;
實作計畫:`docs/superpowers/plans/2026-07-05-plan-b-tsl-generation.md`。

## 其他已實作的周邊功能

- **虛擬人切換**:`web/models/*.vrm` 自動列入下拉選單(`/models.json`),
  也可直接拖放 .vrm 檔;VRoid Studio 可免費自製人物。
- **影片匯出**:⏺ EXPORT 錄一輪播放為 .webm(MediaRecorder,30fps)。
- **軀幹微動**:肩線傾斜/前後差 → 胸骨微轉,避免木頭人感。

## 未來功能候選(依價值排序)

1. **練習模式**:學習者開 webcam,與示範並排 + 鏡像 + 慢速。
2. **即時翻譯**:MediaPipe WASM 在瀏覽器內直接跑,免 Python 端。
3. **Blender/引擎輸出**:把合成結果 retarget 到 armature,輸出
   glTF/FBX 動畫,用於影片生產或遊戲引擎。
4. **詞庫測驗模式**:播手語猜詞。
